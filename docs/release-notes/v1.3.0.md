# Spawnio v1.3.0

`spawn diagnose [PATH]` checks supported Python repository configurations for
stale console-script targets, missing pytest paths and Make recipe config
files, missing requirements includes, and an explicit root user in a final
Python Docker stage. Each warning includes evidence and a next step.

Analysis is local and read-only. Unsupported or incomplete inputs can produce
a partial report. Use `--verbose` for coverage details or `--json` for schema
1.0. CI can use `--fail-on warning` or `--fail-on error` and distinguish a
threshold breach (8) from incomplete analysis (9).
