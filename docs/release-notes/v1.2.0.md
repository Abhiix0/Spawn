# Spawnio v1.2.0 — Repository onboarding

`spawn onboard [PATH]` shows a repository's entry points, suggested development commands, and key files. Use `--verbose` for alternatives and supporting evidence or `--json` for a versioned report suitable for automation.

Onboarding can find FastAPI and Starlette ASGI apps, Flask apps and factories, conventional Django projects, Python console scripts, and module entry points from source and configuration. Install, run, test, lint, and format suggestions are labeled by the evidence available. Both declared commands and inferred candidates still need runtime verification. Analysis is local and read-only.

This release also hardens inspection against symlink and junction escapes, keeps inspection JSON valid UTF-8 for undecodable filenames, and removes absolute paths from invalid-root errors. Reusing file reads and pruning supported Git-local exclusions reduces work on larger repositories.
